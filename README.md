# Studi Kasus 4 Sistem Klasifikasi Persetujuan Pinjaman Loan Approval System
Penerapan supervised learning untuk memprediksi persetujuan pinjaman bank. Mengimplementasikan alur kerja ML lengkap mulai dari data preprocessing, pemisahan training/testing (80:20), pelatihan model Random Forest, hingga evaluasi performa menggunakan Classification Report dan Confusion Matrix guna mencegah overfitting.
